AI Translate 设置

用本机运行的 Index-Translate 模型翻译网页，翻译内容不出本机。

只能填本机地址（127.0.0.1 或 localhost）。默认 http://127.0.0.1:8790。在项目目录运行 scripts/aitd-service.sh install 把本机翻译服务 aitd 设为开机自启（登录后自动加载模型），或运行 npm run aitd 前台启动。

首次启动 aitd 时生成。复制到剪贴板：pbcopy < ~/Library/Application\ Support/ai-translate/api-key

显示方式

一行一条 原文=译文，# 开头的行是注释。术语表存在本机翻译服务 aitd 里，插件和命令行共用；只有段落里出现的术语才会发给模型。

    自动

    按网站设置「总是翻译 / 从不翻译」在工具栏弹窗里改。
