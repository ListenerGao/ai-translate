AI Translate 设置

用本机运行的 Index-Translate 模型翻译网页，翻译内容不出本机。

使用桌面应用时，在 App 的「设置 → 翻译服务」中复制地址。
仅支持本机地址（127.0.0.1 或 localhost），默认为 http://127.0.0.1:8790。
如需将本机翻译服务 aitd 设为开机自启（登录后自动加载模型），可在项目目录运行 scripts/aitd-service.sh install；也可运行 npm run aitd 以前台方式启动。

使用桌面应用时，在 App 的「设置 → 翻译服务」中点「复制密钥」。
该密钥在首次启动 aitd 时生成。可复制到剪贴板：
pbcopy < ~/Library/Application\ Support/ai-translate/api-key

显示方式
术语表

术语表由插件、命令行和桌面应用共用，请在桌面应用的「设置 → 术语表」中查看和编辑。
未安装桌面应用时，可直接编辑 ~/Library/Application Support/ai-translate/glossary.txt，重启 aitd 后生效。

自动

按网站设置「总是翻译 / 从不翻译」在工具栏弹窗里改。
