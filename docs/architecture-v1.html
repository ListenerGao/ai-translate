ai-translate · 架构 V1 · 2026-10-18

先做浏览器插件，其他部分留好接口

第一阶段只做浏览器插件：插件直接连本机的 llama-server，打开文章后边滑动边翻译。翻译核心写成独立的 packages/core，后端藏在 Translator 接口后面。以后加 aitd 服务、命令行和桌面应用时，插件不用重写。

第一阶段架构

边滑动边翻译

每段单独发一个请求，不把几段打包成 JSON。官方插件是 4 段打包，代码里注明小模型容易把格式弄乱、需要重试；单段请求没有这个问题，撤销的粒度也更细。吞吐靠 llama-server 的多槽位并行补上。

预留的三个接口

Translator 接口

插件只认这个接口。第一阶段的实现直连 llama-server，以后换成连 aitd，也可以接 Ollama、LM Studio 或官方免费 API。

packages/core

纯 TypeScript，不依赖浏览器 API：prompt 模板、术语表、结果校验、缓存键。插件现在用，以后 aitd 和 ait 直接复用。

段落协议

插件和后端之间按段落交换数据。这套类型就是以后 aitd 的 /api/translate 接口格式，现在定下来，以后不用改。

模型配置

每个模型一组配置：地址、模型名、推荐参数。9B 和 2B 在设置里切换，以后加模型只加配置。

// packages/core：插件现在用，aitd 和 ait 以后共用
export interface Segment {
  id: string;          // 段落 id，插件里对应一个 DOM 节点
  text: string;
  context?: string;    // 上一段原文，可选
}

export interface TranslateRequest {
  segments: Segment[];
  source: string;      // "auto" 或语言代码
  target: string;
  model: string;       // 对应一组模型配置
  glossary?: { from: string; to: string }[];
}

export interface TranslateResult {
  id: string;
  text: string;
  cached: boolean;
}

export interface Translator {
  // 逐段返回结果；signal 用来撤销已经滑过的段落
  translate(req: TranslateRequest, signal: AbortSignal): AsyncIterable<TranslateResult>;
}

开工后先验证的风险

Chrome 本地网络访问限制

Chrome 142 起，网页访问本机端口要弹权限框。Chrome 团队在扩展论坛答复，有对应 host 权限的插件不受影响，但要在你的 Chrome 上实测。

9B 的速度

粗估一段要几秒，正常阅读跟得上，快速滑动会先看到「翻译中」。实测不够快就默认用 2B，或者让 9B 只翻屏幕内的段落。

正文提取

网站结构各不相同。先覆盖常见文章页（博客、新闻、文档站），跳过代码块和导航；表格和复杂列表后补。

本机端口安全

llama-server 默认允许任何网页跨域访问。启动脚本加 --api-key，只有插件持有密钥。

待确认

  • 待确认

    第一阶段插件直连 llama-server

    建议这样做：最快能用，缓存和术语表先放在插件里，以后加 aitd 只换 Translator 的实现。另一种是先写一个最小的 aitd，插件从第一天就连它，但多一个程序要写和维护。

  • 待确认

    packages/core 用 TypeScript

    建议这样做：插件本来就是 TypeScript；以后 aitd 和 ait 也用 TypeScript + Bun，就能直接复用这份核心代码。以后改用 Rust 的话，这部分逻辑要重写一遍。

默认做法，不需要确认：先支持 Chrome 和 Edge，Firefox 以后再说；默认双语对照显示，可以切换成只显示译文。

分阶段

  1. 浏览器插件

    packages/core、插件和启动脚本：边滑动边翻译、双语对照、缓存、术语表、9B 和 2B 切换。

  2. aitd 服务和 ait 命令行

    插件改连 aitd，缓存和术语表移到服务端；命令行支持 Markdown、SRT。

  3. 桌面应用

    文章和字幕翻译界面、模型下载和切换、全局快捷键。

  4. 扩展

    图片翻译等。
