译文质量评测报告

对象：Index-Translate-2B 的 Q8_0 与 Q4_K_M 两个量化版本，共 35 条真实网页内容（技术文档 10、百科科普 6、学术摘要 4、标题与界面 7、划词短语 8）。其中 16 条两版译文完全相同，19 条分 A/B 各评一次，合计 54 个评分位。评级标准：「准确通顺」可直接发布；「小毛病」能读懂但需润色；「有错误」语义或术语错，必须修。

摘要 硬伤清单 逐条明细 系统性倾向

一、摘要

错误率 15% 是本轮最值得注意的数字：35 条里有 8 个评分位判为「有错误」，其中 4 条是两版共犯，说明瓶颈在模型能力与 prompt 约束，不在量化精度。

二、硬伤清单（必须修）

#问题译文应为范围
6语义反转disposable virtual machines →「可重复使用的虚拟机」一次性（可随意销毁）的虚拟机两版共犯
13化学名错calcium hypochlorite →「氯化钙」次氯酸钙（氯化钙是另一种物质）两版共犯
27术语错mockup →「模型」设计稿 / 原型图（「模型」会与 model 混淆）两版共犯
4未译 + 定语错挂「通过 drop 函数释放内存的 scoping、所有权和内存之间的关系」scoping 应译「作用域」；原文是三项并列，不是「释放内存的」修饰全部两版共犯
7病句「props 是将从父组件传递到子组件的数据方式」props 是把数据从父组件传到子组件的一种方式仅 A（Q8_0）
12指代丢失「能让小鼠在几小时内恢复生机」it 指植物：能让植物在几小时内救活一只老鼠仅 B（Q4_K_M）

三、逐条明细

卡片左边框颜色＝该条最差评级：绿＝准确通顺，琥珀＝小毛病，红＝有错误。两版相同的条目只列一次。

四、系统性倾向与建议

1. 两个量化版本确实打平

19 对可分条目里 Q8_0 胜 7、Q4_K_M 胜 6、平 6。加上盲评页的 12:12:8，两次独立抽样都指向「无可辨差异」。按项目规则取更快的 Q4_K_M（单条 303 ms vs 390 ms，123 tok/s vs 94 tok/s）。

2. 错误集中在四类，与量化无关

类型实例根因判断
专业名词硬译transduction→转译、resolving→解决、truth→真理、mockup→模型词表缺领域术语，模型按字面猜
语义极性判断disposable→可重复使用否定/反向词识别弱
长句结构塌陷#4 三项并列被误修饰、#13 两句粘连、#7 定语堆到失去谓语多定语 + 并列结构解析失败
指代与省略#12 it→植物 丢失、#4 scoping 未译、#20 when fine-tuned 漏译回指链和限定成分易丢

3. 建议动作

  1. 术语表扩容：把 disposable / transduction / mockup / single source of truth / resolve / scoping 六条加进 glossary-and-qa-checklist.html，并同步到 prompt 的术语约束。
  2. P0 检测脚本：译文里出现未在白名单内的连续 ASCII 词（如 scoping、mockup 原词）即报警；专名与化学名走强制查表。
  3. 长句处理：超过 60 词的句子先切分再译，或对并列结构（A, B, and C）单独做结构校验，避免 #4 那种定语错挂。
  4. 回填基准：把本报告的 54 个评分位作为回归基线，每次改 prompt 后重跑同样 35 条，比较「有错误」数量是否下降。
