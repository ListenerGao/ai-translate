## 接口决策（CP0 实测后定稿）

### 段内结构

`packages/core` 不碰 DOM，用一棵抽象的段内结构树，插件负责 DOM 和它之间的转换：

```ts
export type InlineNode =
  | { type: "text"; text: string }
  | { type: "tag"; id: number; children: InlineNode[] }   // 链接、加粗等，里面的文字要翻译
  | { type: "atom"; id: number };                          // 行内代码、图片、换行，原样保留不翻译
```

- `tag`：`a`、`strong`、`b`、`em`、`i`、`u`、`s`、`del`、`mark`、`sub`、`sup`；其他行内元素（如普通 `span`）当作透明，只取文字
- `atom`：`code`、`kbd`、`img`、`br`
- 渲染时按 `id` 找回原元素：`tag` 浅克隆原元素（保留 `href`、`class`、`target` 等属性）再填入译文，`atom` 深克隆原样放回

### 发给模型的文本

把结构树写成带编号标记的文本。候选写法 3 种，CP0 实测后选保持率最高的一种：

| 写法 | 示例 |
|---|---|
| A 尖括号 | `Read <g1>the guide</g1> before running <x2/>.` |
| B 方括号 | `Read [1]the guide[/1] before running [x2].` |
| C 花括号 | `Read {1}the guide{/1} before running {x2}.` |

- prompt 用官方 instTrans 约束格式，加一条硬性要求，措辞参考官方占位符样例：「保留所有的标记（如 …）原样不变，标记内的文字照常翻译」
- 有术语命中时，术语对照和标记要求各占一条硬性要求
- 段落没有任何格式时，仍走 Goal 1 的无约束 prompt，不受影响
- prompt 升版本，旧缓存失效
- 标记两侧多出的空格（Goal 1 CP1 探路时见过 `<g1> 速度显著更快</g1>`）：目标是中文时，去掉标记内侧紧贴中文的空格
- 和 Goal 1 后加的规则衔接：「译文和原文一样不显示」按去掉标记后的文字比较；译文放右边还是下方的判断不变

### 校验与退回

- 译文里的标记集合必须和原文一致：每个 `tag` 成对出现且嵌套合法，每个 `atom` 恰好出现一次，没有多出来的标记；标记顺序可以变（语序调整）
- 不通过就重试 1 次；仍失败，改用 Goal 1 的纯文本 prompt 翻这一段并按纯文本显示
- 缓存记录这一段最终是「带格式」还是「纯文本退回」，回滑时直接复用

- **2B 保不住标记**：CP0 先量化，低于门槛就停下请主人决定，不硬做
- **加了标记后译文变差**：CP0 对照纯文本译文抽查；变差明显就只保留链接这一种格式，其他格式丢弃
