## 目标

在 macOS 上做一个桌面应用「AI Translate」：不开浏览器、不开终端也能用本机模型翻译。它和插件、命令行一样只连 aitd，共用缓存和术语表。

- 菜单栏图标：一眼看到翻译服务和模型的状态；点开能打开翻译窗口、翻译剪贴板、翻译文件、打开设置、重启翻译服务
- 翻译窗口：左边贴原文，右边边输入边出译文；能选原文语言和目标语言，一键复制
- 文件翻译：把 Markdown、SRT 字幕拖进窗口，显示进度，译文写到原文件旁边（规则和 `ait translate` 相同）
- 设置：默认目标语言、术语表（和插件设置页是同一份）、开机启动
- 翻译内容仍然不出本机

## 已确认（2026-10-20 17:18，主人：全部按推荐；第三阶段共用）

1. **技术栈：Swift 原生（推荐）还是 Tauri**
   - Swift 原生（SwiftUI + AppKit）：本机已装 Xcode 26.3、Swift 6.2，不用再装任何工具和依赖。第三阶段要的菜单栏、全局快捷键、读取其他 App 里选中的文字、右键「服务」菜单、开机启动都是 macOS 系统能力，Swift 直接调用；项目本来就只支持 macOS。代价：桌面应用用不了 TypeScript 写的 `packages/core`，所以 Markdown、字幕的拆分和重组放到 aitd 新加的接口里做（仍用 core 的代码），桌面应用只管界面；和架构 V1 写的 Tauri 不同，要出架构 V2
   - Tauri：界面用 TypeScript 写，能直接引用 `packages/core`，和 V1 一致。代价：要先全局安装 Rust 工具链（rustup），新增 `@tauri-apps/cli`、`@tauri-apps/api` 等 npm 依赖，首次编译要下载、编译几百个 Rust 依赖；读取其他 App 选中的文字、服务菜单没有现成插件，仍要写 Rust 去调 macOS 接口
2. **桌面应用只做 aitd 的客户端（推荐）**：和插件、命令行一样连 `127.0.0.1:8790`，aitd 仍由开机自启管理。不把 aitd 和 Node 打包进 App：打包要带上 Node 运行时，还要处理 App 和开机自启谁来管模型，复杂很多，个人使用用不上。没连上 aitd 时提示怎么启动
3. **安装位置（需授权）**：`scripts/install-desktop.sh install` 构建后装到 `~/Applications/AI Translate.app`（用户目录，不要管理员密码）；`uninstall` 删除
4. **开机启动（需授权）**：用系统的「登录项」，默认打开，设置里可以关。Goal 7 的全局快捷键要 App 在运行才有效
5. **签名用本机自签名证书（推荐，需授权）**：在登录钥匙串里建一个只用来给这个 App 签名的自签名证书。Goal 7 的划词要在「系统设置 → 隐私与安全性 → 辅助功能」里给 App 授权；用临时签名（ad-hoc）时，每次重新构建 App 的身份都会变，授权会失效、要重新授权（CP0 实测确认）。有固定证书就授权一次长期有效。不建也能用，只是每次更新 App 后要重新授权
6. **划词取词方式（Goal 7，需主人授权辅助功能）**：先用 macOS 辅助功能接口读当前 App 里选中的文字；读不到再模拟一次 `⌘C`，从剪贴板取，取完把剪贴板恢复原样。另外始终提供两种不需要任何权限的方式：「翻译剪贴板」快捷键，以及右键菜单「服务 → 用 AI Translate 翻译」

结论：用 Swift 原生（第 1 项）；App 只做 aitd 的客户端（第 2 项）；第 3~5 项的安装、登录项、签名证书已授权；第 6 项的辅助功能授权由主人在 Goal 7 时在系统设置里点。

### aitd 新接口

- `POST /api/translate-document`：请求体 `{ "format": "markdown" | "srt", "text", "source", "target", "model", "bilingual", "lane", "glossary" }`；`model` 必须是 aitd 当前加载的模型（和 `/api/translate` 相同），`lane` 默认 `batch`，`glossary` 可选。用 core 的 `parseMarkdown`、`parseSrt` 拆段，逐段走现有的调度和缓存，最后重组
- 返回 NDJSON：进度行 `{"type":"progress","done","total"}`；最后一行 `{"type":"done","text","failed":[{"line","error"}]}`。SRT 格式错误返回 400 `{"error":{"code":"format","line","message"}}`
- 客户端断开就撤销还没开始的段落（和 `/api/translate` 相同）；请求体上限沿用 1MB（Markdown 文档和整部电影的字幕都远小于这个），超过时返回 413，App 提示「文件太大」
- 鉴权、`Host` 和来源检查和现有接口相同；App 的请求不带 `Origin`，和命令行一样放行

### 翻译窗口

- 左边输入，停止输入 0.5 秒后开始翻译（`⌘↩` 立即翻）；按空行分段，每段一个请求，按段落顺序显示，哪段先翻好就先显示哪段
- 再次输入时撤销上一次还没完成的请求；没变的段落直接命中缓存
- 原文语言默认「自动」，目标语言默认取设置；「复制译文」按钮
- 一次最多 2 万字，超过时提示改用文件翻译
- 拖文件到窗口上就是文件翻译
- 关窗口（⌘W 或点关闭）时清空原文、译文、提示和窗口里记住的段落，原文语言、目标语言保留（2026-10-20 19:01 主人定）；翻过的内容在 aitd 缓存里，再翻照样立即出

### 文件翻译

- 拖到翻译窗口，或菜单「翻译文件…」打开；支持 `.md`、`.markdown`、`.srt`
- 只认 UTF-8，不是 UTF-8 时提示转码方法（和 `ait` 相同）
- 进度条，可以取消；完成后提示写到了哪里，按钮「在访达中显示」；有段落没翻成时列出行号，这些段落保留原文

### 设置
